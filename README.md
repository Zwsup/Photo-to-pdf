Offline Photo to PDF
A simple, fully offline tool for converting photos into A4 PDF files without uploading them to any server.

Features:

-Fully offline usage

-Support for up to 100 photos

-Place each photo on a separate A4 page

-A4 portrait or landscape orientation

-Adjustable margins

-Fit photos within the page or fill the available area

-Photo preview

-Save PDF through the browser's print dialog

-Microsoft Print to PDF support

-Photos are not uploaded to any server


Usage:

-Open offline_photo_to_pdf_100.html using Chrome, Edge, or another modern browser.

-Select your photos using the Choose Photos input.

-You can select up to 100 photos.

-Choose the page orientation: Portrait or Landscape.

-Adjust the page margins.

-Select the photo layout:

-Contain: Keeps the entire photo visible.

-Cover: Fills the available area; some parts of the photo may be cropped.

-Click Create PDF / Print.

-In the print dialog, select Save as PDF or Microsoft Print to PDF.

-Save your PDF file.


Page Layout:

Each photo is placed on a separate A4 page.

Examples:

1 photo → 1-page PDF

2 photos → 2-page PDF

100 photos → 100-page PDF


Privacy;

This application does not upload photos to any server. Photos are processed locally inside the browser on the user's computer.

No internet connection, backend, database, or API key is required to use the application.


Requirements:

-A modern web browser

-Google Chrome, Microsoft Edge, Mozilla Firefox, or another modern browser

-Ability to open the HTML file on your operating system

No installation is required.

Limitations:

-A maximum of 100 photos can be selected at once.

-Each photo is placed on a separate A4 page.

-PDF saving is handled through the browser's print dialog.

-Very high-resolution photos may increase browser memory usage and PDF file size.
